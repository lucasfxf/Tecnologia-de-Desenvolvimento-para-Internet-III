# Trabalho 04 - Fundamentos do HTTP

Disciplina: Tecnologias de Desenvolvimento para Internet III

## Objetivo
Explorar o protocolo HTTP utilizando Java Servlets.

## Servlets desenvolvidos

1. GET /headers - Análise dos cabeçalhos HTTP.
2. POST /request-body - Manipulação do corpo da requisição.
3. GET /session - Controle de sessão e cookies.
4. GET /status - Testes de códigos de status HTTP.
5. OPTIONS /methods - Métodos HTTP suportados.

## Tecnologias
- Java
- Jakarta Servlet 6.0
- Apache Tomcat 10.1
- Eclipse IDE
